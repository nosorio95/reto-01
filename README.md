# Reto Tecnico 01 - Registro como Proveedor

## Descripcion

Agente conversacional para automatizar el registro de proveedores.

## Instalacion

npm install

## Ejecutar servidor

npm run dev

## Ejecutar demo

npm run demo

## Endpoints

GET /api/health
POST /api/chat
GET /api/sessions/:id

## Herramientas

- leer_solicitud
- mapear_campos
- generar_formulario
- armar_paquete
- simular_envio
